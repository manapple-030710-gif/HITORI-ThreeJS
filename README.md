# HITORI / Environment study 01

白〜淡いグレーの空と、ゆっくり揺らぐ水面だけのThree.js環境映像です。人物・建物・雲・霧はありません。

## 起動方法（このPC）

1. このフォルダの **start.cmd** をダブルクリックします。
2. ブラウザで http://127.0.0.1:5173 が開きます。
3. 終了するときは起動したターミナルで `Ctrl+C` を押します。

パッケージは導入済みです。初回起動時の追加ダウンロードは不要です。HTMLファイルを直接ダブルクリックせず、start.cmdを使ってください。すでにサーバーが起動している場合は、ブラウザで上記URLを開くだけです。

## 別のPCで起動する場合

Node.js 22 LTS以降を用意し、このフォルダでターミナルを開いて実行します。

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。pnpmを使う場合は `pnpm install` / `pnpm dev` です。本番用の静的ファイルは `npm run build` で `dist/` に作成し、`npm run preview` で確認できます。

## 操作

デバッグ表示・速度／振幅の倍率は撤去済みです。停止中も描画ループを継続し、波の時間だけを固定します。再開時は保持した時間から動きます。

- 右上「環境を調整」：光の強さ、水の速さ、揺らぎ、空の色、霧の開始距離・濃さ・色。
- **H**：すべての操作UIとマウスカーソルを隠す／戻す。右下にマウスを合わせても復帰ボタンを表示できます。
- **一時停止**：波の時間だけを停止。再生で続きから動きます。
- **PNG保存**：UIなしの1920×1080静止画を保存。
- **全画面**：ブラウザの全画面表示。終了はEsc。

描画解像度は1920×1080、カメラと画角は完全固定です。ウィンドウが違う比率の場合も16:9を保ち、余白を付けます。波はフレームレートに依存しない時間差分で更新します。外部画像・CDN・音声は使用しません。

## ファイルと今後の拡張

- `src/config.js`：初期設定の入口。空の天頂・水平線の色、光の強さと方向、水の色・速度・揺らぎ・粗さ（water.roughness）。
- `src/environment/sky.js`：空のグラデーションと柔らかい光。空の色関数を水面の反射にも共有。
- `src/environment/water.js`：12方向の波と6段階の不規則な微細波、視線角に応じたFresnel反射、粗さに応じた空の反射を持つGPUシェーダー。画素より小さな波は抑えて粗さに置き換え、遠景のちらつきを軽減。
- `src/environment/index.js`：空・水・照明の組み立てと更新。
- `src/main.js`：固定カメラ、描画ループ、UI。
- `src/style.css`：操作パネルと16:9表示。

霧はenvironment内に追加し、空・水のシェーダーにも距離に応じた色の合成を追加します。雲はsky.jsの共有関数へ追加すると水面の空反射にも反映できます。時間帯変更はconfigの空色・光方向・光量を補間してenvironment.apply()へ渡す構成にできます。いずれも現段階では未実装です。

水面は法線を動かす軽量な表現で、実際の水位の上下や物体の映り込みは未実装です。後から人物や建築を追加する段階で、必要に応じて反射パスを拡張してください。
